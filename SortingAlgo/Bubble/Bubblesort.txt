Bubble sort is a sorting algorithm that arranges a list of numbers in ascending or descanding order.
it repeatedly goes through the list.
it compares neighboring elements and swaps them if they are in the wrong order.
The largest element " bubbles up " to its correct position in each pass through the list .


LOGIC:-
1. Look at the list of numbers.
2. Compar each number with the one next to it.
3. If the first numbmer is bigger than the second . swap them.
4. Move to thhe next pair and repeat.
5. After going through the entire list once , the largest number will be at the end .
6. Repeat the process for the remaining  unsoerted part of the list until everything is in order.

Time Complexity Overview:-

Bubble Sort Has three cases:-

Case               Description                              Time Complexity

Best Case        The list is already sorted                     O(n)

Worst Case        The list is sorted in reverse order           O(n^2) 

Average Case      Random order of element                       O(n^2)





Space Complexity:-
