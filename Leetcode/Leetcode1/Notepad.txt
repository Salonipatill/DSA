stringstream is a class from the <sstream> library.

it allows us to treat a string like input/output stream.

Header file:-

#include<sstream>

IMP:-

Normal Stream                            Works With
 cin                                     keyboard input
 cout                                    screen output
 stringstream                            string(text)



 Types in  <sstream>

 1. stringstream
 Read + Write 

 2. istringstream
 only input (read from string)

 3. ostringstream
 only output(write to string)



How It Works

1. Create a stringstream
stringstream ss("Hello 123");

2. Extract data(like cin)
string word;
int num;

ss>>word>>num;


OUTPUT:-
word = "Hello"
num = 123

3. Insert data(like cout)

stringstream ss;
ss<<"Age:"<<20;

CONVERT TO STRING

string result = ss.str();

OUTPUT:-

"Age: 20"


Key Functions

.str()
Get the full string
string s = ss.str();

.clear()
Reset error flags

.str("")
Clear content
