## Binary Search Tree:-
A Binary Search Tree (BST) is a special type of binary tree that follows a specific ordering rule.

## BST Property

Left Subtree  <  Root  <  Right Subtree

# or

All values in Left subtree are smaller.

Root contains the current value.

All values in Right subtree are greater.

# Example

        50
      /    \
    30      70
   /  \    /  \
 20   40 60   80

Notice:-20 < 30 < 40 < 50 < 60 < 70 < 80


Every node satisfies
Left < Root < Right
