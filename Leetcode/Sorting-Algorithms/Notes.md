## Sorting means 
arranging elements in a particular order.

## Ascending: 
1, 2, 3, 4, 5

## Descending: 
5, 4, 3, 2, 1


Best order to learn sorting
Bubble Sort → Learn the basic idea of swapping and loops.
Selection Sort → Understand finding minimum and placing it.
Insertion Sort → Understand how elements are shifted and inserted.
Merge Sort ⭐ → Learn Divide and Conquer properly.
Quick Sort ⭐ → Learn pivot and partition.
Heap Sort → Easy for you after studying Heap.
